# MVP Roadmap Checklist: бот-помощник project-менеджера

Документ фиксирует, что входит в рабочий MVP для хакатона, что делать после MVP для максимума баллов и как проверить готовность демо.

## Короткое описание готовности

привет, основной функционал сделан:

создаются команды с менеджером, менеджер прикрепляет бота к Telegram-чату и к канбан-доске YouGile

бот работает только в зарегистрированных командах, понимает роли менеджера, участника и админа

бот читает сообщения из чата, находит задачи, дедлайны, исполнителей и краткое описание

бот не создает задачи из каждого сообщения подряд, игнорирует обсуждения и шутки, объединяет несколько сообщений в контекст и убирает дубли

после подтверждения бот создает карточку в YouGile, заполняет название, исполнителя, дедлайн и описание

бот синхронизирует задачи со своей базой и не теряет их, если внешний API временно недоступен

из чата можно двигать статусы: человек пишет «беру в работу», «готово», «закрыл», и бот переносит карточку по канбану

есть команды для просмотра задач, синка с канбаном и личного списка задач

есть напоминания по дедлайнам: бот пишет лично исполнителю, не спамит, учитывает статусы «болею», «экзамен», «отпуск» и не напоминает по закрытым задачам

есть вечерний синк: участники пишут, что сделали за день, бот сопоставляет отчеты с задачами, предлагает закрывать готовые задачи и отправляет менеджеру сводку

есть работа с аудио и встречами: бот принимает голосовое или запись, расшифровывает, делает summary, вытаскивает задачи, дедлайны и ответственных, создает карточки в канбане

есть реалтайм-транскрибация встречи и подсказки по похожим задачам, есть ручное сопоставление говорящих с Telegram-пользователями

есть база знаний команды: можно загружать файлы, заметки и протоколы встреч, искать по архиву задач и встреч, задавать вопросы через Telegram

сверх базового MVP уже добавлены аналитика скорости выполнения задач, рекомендации по развитию навыков, подбор курсов, геймификация и RPG-профиль участника

из того, что осталось дополировать:

нужно прогнать стабильный демо-сценарий несколько раз от начала до конца

нужно закрыть мелкие UX-моменты: `/help`, кнопки для низкой уверенности, утренние и вечерние напоминания, быстрые кнопки в напоминаниях

нужно подготовить запасной демо-скрипт на случай падения внешнего API

веб-панель менеджера, красивые отчеты, командные рейтинги и расширенные госрегламенты остаются как развитие после MVP

## MVP 5. Вечерний синк

Это сильная фича для кейсодержателя, поэтому её лучше сделать сразу после базового канбана.

- [ ] В заданное время бот пишет в чат: «Вечерний синк»
- [x] Каждый участник отправляет, что сделал за день
- [x] Бот сопоставляет отчёт с задачами в канбане
- [x] Если человек написал «готово», бот предлагает закрыть задачу
- [ ] Если задача не обновлялась, бот подсвечивает её

## MVP 6. Встречи и аудио

Для быстрого прототипа не стоит начинать с полноценного автоподключения к Яндекс Телемосту. Сначала нужна бизнес-функция: бот принимает запись встречи или голосовое, расшифровывает, делает summary и создаёт задачи. Потом можно добавить «присутствие» на встрече.

### Минимум

- [x] Бот принимает аудиофайл или голосовое сообщение
- [x] Бот отправляет аудио в Whisper, Yandex SpeechKit или другой STT
- [x] Бот получает текстовую расшифровку
- [x] Бот делает краткое summary встречи
- [x] Бот извлекает задачи, дедлайны и ответственных
- [ ] Бот показывает список найденных задач на подтверждение
- [x] Бот создаёт карточки в канбане
- [x] Бот прикладывает summary к карточкам или в отдельный отчёт

### Усиление

- [ ] Сделать веб-страницу «Запись встречи»
- [x] Захватывать звук с микрофона или системного аудио

- [x] Автоматически отправлять summary в Telegram после встречи

## Главный приоритет

Сначала нужно сделать связку:

```text
Telegram -> извлечение задачи -> подтверждение -> карточка в канбане -> напоминание
```

Всё остальное добавляется поверх этой связки. Без неё проект выглядит как идея; с ней это уже рабочий MVP.
