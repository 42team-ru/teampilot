# fix-sync-processor-per-line-qdrant-search

## Goal

После объединения сообщений вечернего синка в один `raw_text` (бот отправляет все сообщения одним запросом) — Qdrant получает один векторный запрос со всем текстом. Если находится хотя бы один матч, LLM-fallback не срабатывает, и задачи из других строк отчёта теряются. Нужно делать поиск по каждой строке отдельно.

## Requirements

* Разбить `raw_text` по строкам (`\n`), убрать пустые
* Для каждой строки — отдельный `search_tasks(line, team_id, limit=5)`
* Собрать все `task_id` выше порога в один set, без дублей
* Если строка одна — поведение не меняется (обратная совместимость)
* LLM-fallback срабатывает только если ни одна строка не дала матч

## Acceptance Criteria

* [ ] Пользователь пишет "сделал bff и документацию" → в драфте обе задачи
* [ ] Если текст однострочный — поведение идентично текущему
* [ ] LLM-fallback срабатывает когда ни одна строка ничего не нашла

## Definition of Done

* `sync_processor.py` изменён, тесты зелёные

## Out of Scope

* Изменения в боте или Spring-монолите
* Изменение LLM-fallback логики
