# Сообщение об ошибке при неподдерживаемом формате в /upload

## Goal

Показывать понятное сообщение когда пользователь отправляет файл неподдерживаемого типа (документ, фото) вместо аудио/видео.

## Requirements

* Отдельный обработчик для `F.document | F.photo` — сообщение: «Этот тип файла не поддерживается. Отправьте аудио или видео.»
* Catch-all обработчик (не-файловые сообщения) — сообщение: «Пожалуйста, отправьте аудио или видео файл. Используйте /cancel для отмены.»

## Acceptance Criteria

* [ ] Отправка документа или фото → «Этот тип файла не поддерживается...»
* [ ] Отправка текста/стикера → общее сообщение про аудио/видео
* [ ] Принятые типы (audio, voice, video, video_note) загружаются без изменений

## Technical Notes

* Файл: `bot/handlers/upload.py`
* Добавить handler между `handle_upload_file` и `handle_non_file_while_waiting`
* Фильтр: `FileUploadStates.waiting_for_file, F.document | F.photo`
