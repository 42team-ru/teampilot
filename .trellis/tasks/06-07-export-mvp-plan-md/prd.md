# Export MVP plan to Markdown

## Goal

Сохранить и поддерживать подготовленный чек-лист MVP и post-MVP фич в Markdown-файле, чтобы команда могла отмечать прогресс галочками и использовать документ как рабочий план.

## What I already know

- Пользователю нужен `.md`-файл с полным планом по MVP бота-помощника project-менеджера.
- В проекте уже есть папка `docs/` с хакатонными материалами.
- Нужен формат с чекбоксами.
- Следующий шаг: пройти по пунктам чек-листа в несколько проходов и отметить уже реализованное на основании кода/документации проекта.

## Requirements

- Создать отдельный Markdown-документ в `docs/`.
- Сохранить блоки: главный MVP, Telegram, извлечение задач, канбан, напоминания, вечерний синк, встречи, демо, post-MVP фичи, порядок разработки, критерии готовности.
- Использовать Markdown-чекбоксы `- [ ]`.
- Проверить реализацию по репозиторию в несколько проходов.
- Менять `- [ ]` на `- [x]` только для пунктов, которые подтверждаются найденной реализацией.
- Для спорных или частично реализованных пунктов оставить чекбокс пустым и не завышать готовность.

## Acceptance Criteria

- [ ] План сохранён в `docs/mvp-roadmap-checklist.md`.
- [ ] Документ читается как самостоятельный roadmap.
- [ ] В документе есть чекбоксы для отслеживания выполнения.
- [ ] Реализованные пункты отмечены в `docs/mvp-roadmap-checklist.md`.
- [ ] В финальном ответе указано, какие проходы выполнены и какие зоны остались сомнительными.

## Out of Scope

- Изменение кода.
- Реализация функциональности.
- Обновление презентации.
