# PRD: Вечерний синк

## Цель
Ежедневно в 18:00 бот собирает отчёты участников команды, сопоставляет их с задачами в YouGile, двигает выполненные задачи и отправляет summary менеджерам.

---

## Флоу

### 1. Запуск синка (18:00, Spring Cron)
- `EveningSyncScheduler` публикует в `bots.notifications`
- Бот пишет в Telegram-чат команды: _"Вечерний синк: напишите, что сделали сегодня"_

### 2. Сбор ответов (окно 18:00–19:00)
- Ответы пользователей поступают в `messages.raw` с флагом `syncMode: true`
- `SyncStateService` хранит состояние: кто ответил в этом окне

### 3. LLM-обработка
- LLM Worker получает сообщение + список активных задач пользователя из YouGile API
- Сопоставляет текст с задачами
- Возвращает черновик: список пар (текст юзера → задача YouGile или null)

### 4. Подтверждение пользователем
Бот показывает черновик:
```
Понял так:
1. "Закончил API" → Реализовать API endpoint ✅
2. "Презентация" → задача не найдена в YouGile ❓
```
Кнопки:
- **[✅ Всё верно]** — bulk-подтверждение всего списка
- **[✏️ Изменить]** — бот спрашивает номер задачи → юзер уточняет → черновик обновляется → снова показывается список
- **[❌ Отклонить]** — синк отменяется для этого юзера

### 5. После подтверждения
**Найденные задачи:**
- `llm.status.change` → Spring → YouGile API: статус → Done

**Незнакомые задачи (не найдены в YouGile):**
- `llm.tasks.create` (статус = Done сразу)
- Spring уведомляет всех `TeamRole.MANAGER` команды через `TaskNotificationRecipientResolver`:
  _"Пользователь X выполнил задачу 'Y' — подтвердить создание?"_ + кнопки [✅/❌]
- Менеджер аппрувит → задача создаётся в YouGile со статусом Done

### 6. Закрытие окна и Summary (19:00, Spring Cron)
`EveningSyncScheduler` собирает по команде:
- Кто отчитался
- Какие задачи закрыты
- Кто не ответил

Публикует в `bots.notifications` → бот отправляет каждому `TeamRole.MANAGER` команды:
```
Вечерний синк — итоги:
✅ Отчитались: Вася, Петя (5 задач закрыто)
❌ Не ответили: Коля
📋 На аппруве у менеджера: 2 новые задачи
```

## Новые компоненты

| Компонент | Слой | Описание |
|---|---|---|
| `EveningSyncScheduler` | Spring | Cron 18:00 (запуск) + 19:00 (summary) |
| `SyncStateService` | Spring | Хранит состояние окна: кто ответил, черновики |
| `SyncResponseConsumer` | Spring | Читает `messages.raw` с `syncMode: true` |
| `SyncSummaryPublisher` | Spring | Формирует и шлёт summary менеджерам |

## Изменения в существующих компонентах

| Компонент | Изменение |
|---|---|
| `MessageBatchEvent` | Добавить поле `syncMode: boolean` |
| LLM Worker | Новый обработчик sync-режима: сопоставление текста с задачами YouGile |
| `bots.notifications` | Новые типы сообщений: sync-prompt, sync-summary |

---

## Kafka-топики

| Топик | Направление | Описание |
|---|---|---|
| `messages.raw` | Bot → Spring | Уже существует; добавить флаг `syncMode` |
| `bots.notifications` | Spring → Bot | Уже существует; новые типы: sync-prompt, sync-draft, sync-summary |
| `llm.tasks.create` | LLM → Spring | Уже существует; новая задача с `status=Done` |
| `llm.status.change` | LLM → Spring | Уже существует |

---

## Менеджер
Определяется через `TeamRole.MANAGER` в `TeamUser`. Резолвинг через существующий `TaskNotificationRecipientResolver`.

---

## Out of scope (v1)
- Заблокированные задачи
- Настройка времени синка
- Индивидуальные напоминания не ответившим
