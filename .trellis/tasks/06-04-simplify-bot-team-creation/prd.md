# Упростить создание команды в боте

## Проблема

Администраторский сценарий создания команды запрашивает необязательные поля
`kanban_id` и `kanban_api_key` отдельными шагами 3 и 4. Эти данные при создании
команды не нужны и могут быть настроены позже.

## Требования

- Оставить в сценарии создания команды только два шага:
  1. Telegram ID менеджера.
  2. Название команды.
- После валидного названия сразу создавать команду.
- Не передавать значения `kanban_id` и `kanban_api_key`, чтобы сервис применял
  существующие значения по умолчанию.
- Удалить недостижимые обработчики, FSM-состояния и admin-клавиатуру пропуска,
  которые обслуживали шаги 3 и 4.
- Обновить номера шагов в сообщениях с `1/4`, `2/4` на `1/2`, `2/2`.

## Критерии приёмки

- После ввода названия бот вызывает создание команды без дополнительных вопросов.
- В запросе к backend отсутствуют `kanbanId` и `kanbanApiKey`.
- Старые состояния и callback-обработчики шагов 3 и 4 отсутствуют.
- Python-код бота компилируется без ошибок.
